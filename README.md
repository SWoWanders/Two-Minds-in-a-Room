# Two Minds, One Room

A cozy 3D room where two characters, Pip and Moss, are each controlled by a different free AI model running entirely in your browser (WebLLM + WebGPU). No server, no API keys, no cost.

- **Start with AI:** pick a model for each character; they download once and are cached.
- **Scripted demo:** works anywhere, no AI needed.
- Type an event (like "a cat walks in") and both characters react.

Needs a WebGPU browser (Chrome on Android or desktop).
